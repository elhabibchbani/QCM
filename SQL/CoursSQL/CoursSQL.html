What is SQL?

SQL (Structured Query Language) is the standard language used to create, manage, and manipulate relational databases. It allows users to store, retrieve, update, and delete data efficiently.

What Can You Do with SQL?

  • Create databases.
  • Create, modify, and delete tables.
  • Insert, update, and delete records.
  • Retrieve data using SQL queries.
  • Sort and filter data.
  • Group and summarize information.
  • Create indexes and views.
  • Manage users and database permissions.
  • Create database backups and restore them.

Why Learn SQL?

SQL is one of the most important programming languages for working with relational databases such as MySQL, SQL Server, PostgreSQL, Oracle, and SQLite. It is widely used in web development, data analysis, business intelligence, and enterprise applications.

CREATE DATABASE

The CREATE DATABASE statement is used to create a new database.

Syntax

  CREATE DATABASE database_name;

Example

 CREATE DATABASE School;

Explanation

  • CREATE DATABASE creates a new database.
  • database_name is the name of the database to be created.


DROP DATABASE

The DROP DATABASE statement is used to delete an existing database.

Syntax

 DROP DATABASE database_name;

Example

 DROP DATABASE School;

Explanation

  • DROP DATABASE permanently deletes a database.
  • database_name is the name of the database to be deleted.

Note

Warning: Deleting a database is permanent. All tables and data inside the database will be lost.



BACKUP DATABASE

The BACKUP DATABASE statement is used to create a backup copy of an existing database.

Syntax


BACKUP DATABASE database_name
TO DISK = 'file_path';

Example


BACKUP DATABASE testDB
TO DISK = 'D:\backups\testDB.bak';

Explanation

  • BACKUP DATABASE creates a backup of the specified database.
  • TO DISK specifies the location where the backup file will be saved.
  • .bak is the standard extension for SQL Server backup files.

Note

The destination folder must exist, and the SQL Server service must have permission to write to the specified location.



CREATE TABLE

The CREATE TABLE statement is used to create a new table in a database.

Syntax


CREATE TABLE table_name (
    column1 datatype constraints,
    column2 datatype constraints,
    column3 datatype constraints,
    ...
);

Example


CREATE TABLE Employe (
    Id INT IDENTITY(1,1) PRIMARY KEY,
    Nom VARCHAR(100) NOT NULL,
    Prenom VARCHAR(100),
    Email VARCHAR(255) UNIQUE,
    Age INT CHECK (Age >= 18),
    Salaire DECIMAL(10,2) DEFAULT 3000,
    DateEmbauche DATE,
    DepartementID INT,
    FOREIGN KEY (DepartementID)
        REFERENCES Departement(Id)
);

Explanation

Element Description
CREATE TABLE Creates a new table.
IDENTITY(1,1) Automatically generates an incremental ID (SQL Server).
PRIMARY KEY Uniquely identifies each record.
NOT NULL Does not allow NULL values.
UNIQUE Ensures all values are unique.
CHECK Restricts the values allowed in a column.
DEFAULT Sets a default value.
FOREIGN KEY Creates a relationship with another table.


DROP TABLE

The DROP TABLE statement is used to permanently delete an existing table from a database.

Syntax


DROP TABLE table_name;

Drop a Table Only If It Exists


DROP TABLE IF EXISTS table_name;

Example


DROP TABLE IF EXISTS Employe;

Explanation

Element Description
DROP TABLE Deletes an existing table from the database.
IF EXISTS Prevents an error if the table does not exist.
table_name The name of the table to be deleted.

Note

Warning: Dropping a table permanently removes the table structure and all its data.



INSERT INTO

The INSERT INTO statement is used to insert new records into a table.

Syntax


INSERT INTO table_name (column1, column2, column3, ...)
VALUES (value1, value2, value3, ...);

Example


INSERT INTO Persons (PersonID, LastName, FirstName, Address, City)
VALUES (1, 'Naji', 'Ayoub', 'Hay Salam', 'Agadir');

Explanation

Element Description
INSERT INTO Inserts a new record into a table.
Persons The name of the table.
(PersonID, LastName, FirstName, Address, City) The columns where the data will be inserted.
VALUES Specifies the values to insert.
(1, 'Naji', 'Ayoub', 'Hay Salam', 'Agadir') The data inserted into the new row.

Result

A new record will be added to the Persons table.



ALTER TABLE

The ALTER TABLE statement is used to add, delete, or modify columns in an existing table.

Add a Column

Use the ADD statement to add a new column.


ALTER TABLE table_name
ADD column_name datatype;

Example


ALTER TABLE Persons
ADD Email VARCHAR(255);

Drop a Column

Use the DROP COLUMN statement to delete an existing column.


ALTER TABLE table_name
DROP COLUMN column_name;

Example


ALTER TABLE Persons
DROP COLUMN Email;

Rename a Column

Use the RENAME COLUMN statement to rename an existing column.


ALTER TABLE table_name
RENAME COLUMN old_name TO new_name;

Example


ALTER TABLE Persons
RENAME COLUMN LastName TO FamilyName;

Explanation

Statement Description
ALTER TABLE Modifies the structure of an existing table.
ADD Adds a new column to the table.
DROP COLUMN Removes a column from the table.
RENAME COLUMN Changes the name of an existing column.

Note

Note: The syntax for renaming a column may vary depending on the database system (MySQL, SQL Server, PostgreSQL, Oracle, etc.).



CREATE INDEX

The CREATE INDEX statement is used to create an index on one or more columns in a table. An index improves the speed of data retrieval operations.

Syntax


CREATE INDEX index_name
ON table_name (column1, column2, ...);

Example


CREATE INDEX idx_lastname
ON Persons (LastName);

Example with Multiple Columns


CREATE INDEX idx_name
ON Persons (LastName, FirstName);

Explanation

Element Description
CREATE INDEX Creates a new index.
index_name The name of the index.
ON Specifies the table where the index will be created.
table_name The name of the table.
(column1, column2, ...) The column or columns used to create the index.

Advantages

  • Speeds up SELECT queries.
  • Improves search performance on large tables.
  • Can be created on one or multiple columns.

Note

Note: Creating too many indexes may slow down INSERT, UPDATE, and DELETE operations because the indexes must also be updated.



CREATE VIEW

The CREATE VIEW statement is used to create a virtual table based on the result of a SQL query.

Syntax


CREATE VIEW view_name AS
SELECT column1, column2, ...
FROM table_name
WHERE condition;

Example


CREATE VIEW ActiveEmployees AS
SELECT Id, Nom, Prenom, Salaire
FROM Employe
WHERE Salaire > 3000;

Using the View


SELECT * FROM ActiveEmployees;

Explanation

Element Description
CREATE VIEW Creates a virtual table.
view_name The name of the view.
AS Defines the SQL query used by the view.
SELECT Retrieves the data displayed by the view.
FROM Specifies the source table.
WHERE Filters the records included in the view.

Advantages

  • Simplifies complex SQL queries.
  • Improves data security by exposing only selected columns.
  • Can be reused like a regular table.
  • Makes SQL code easier to read and maintain.

Note

A VIEW does not store data itself. It displays data from one or more tables each time it is queried.



SQL SELECT

The SELECT statement is used to retrieve data from a database.

Statement Description Example
SELECT Retrieves data from a table. SELECT * FROM Persons;
AS Renames a column or table temporarily. SELECT LastName AS FamilyName FROM Persons;
FROM Specifies the table to query. SELECT * FROM Persons;
WHERE Filters records based on a condition. SELECT * FROM Persons WHERE City='Agadir';
AND / OR / NOT Combines or negates conditions. WHERE Age > 18 AND City='Agadir'
ORDER BY Sorts the result. ORDER BY LastName ASC;
ASC Sorts in ascending order. ORDER BY Age ASC;
DESC Sorts in descending order. ORDER BY Age DESC;
DISTINCT Returns unique values only. SELECT DISTINCT City FROM Persons;
IS NULL Finds NULL values. WHERE Address IS NULL;
IS NOT NULL Finds non-NULL values. WHERE Address IS NOT NULL;
LIMIT Limits the number of rows (MySQL). SELECT * FROM Persons LIMIT 5;
TOP Limits the number of rows (SQL Server). SELECT TOP 5 * FROM Persons;
LIKE Searches using patterns. WHERE LastName LIKE 'A%';
COUNT() Counts the number of rows. SELECT COUNT(*) FROM Persons;
GROUP BY Groups rows with the same values. GROUP BY City;
HAVING Filters grouped results. HAVING COUNT(*) > 2;
BETWEEN Selects values within a range. WHERE Age BETWEEN 18 AND 30;
IN Matches any value in a list. WHERE City IN ('Agadir','Rabat');
MAX() Returns the maximum value. SELECT MAX(Salary) FROM Employe;
MIN() Returns the minimum value. SELECT MIN(Salary) FROM Employe;
AVG() Returns the average value. SELECT AVG(Salary) FROM Employe;
SUM() Returns the total sum. SELECT SUM(Salary) FROM Employe;
INNER JOIN Returns matching records from both tables. SELECT * FROM Orders INNER JOIN Persons ON Orders.PersonID = Persons.PersonID;
LEFT JOIN Returns all rows from the left table and matching rows from the right table. SELECT * FROM Persons LEFT JOIN Orders ON Persons.PersonID = Orders.PersonID;
